FAQ

Windows SmartScreen says the app is unsigned — is it safe?

BoostX is not yet code-signed. Download only from this page, verify the file name BoostX-Setup.exe, and proceed only if you trust the source.

Does BoostX change my BIOS automatically?

No. Firmware is never written from Windows. You get menu paths and optional shutdown /r /fw — changes are manual in UEFI.

Can I undo everything?

Per-tweak registry backup, Revert all, and System Restore when available.

Will this ban me in CS2 / VALORANT?

BoostX adjusts Windows settings and configs — no game injection. Use at your own discretion.
